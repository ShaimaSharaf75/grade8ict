HTML Tags Quick Reference Sheet

<!DOCTYPE html>

Tells the browser that this document is written in HTML5.

<html> ... </html>

The root container tag for all content on the web page.

<head> ... </head>

Contains metadata, page title, and information for browsers (not displayed directly on page body).

<body> ... </body>

Contains all visible website content like text, images, lists, and links.

<p> ... </p>

Defines a paragraph. Automatically creates spacing above and below text.
