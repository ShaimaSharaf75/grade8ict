Teach: Key HTML Vocabulary & Structure

10 Minutes • 20 Points • Core Tags & Website Architecture

HTML

Hypertext Markup Language, a language used to create web pages.

HTML Element

A piece of a website, marked by a start tag and often closed with an end tag.

HTML Tag

Special set of characters indicating start/end of an element (e.g., <p>).

Website Content

The actual text, headings, and images displayed on a web page.

Website Structure

How content is organized using nested tags (head, body, paragraph).

<p></p> Paragraph

Defines a block paragraph of text. Browser automatically adds spacing before and after.

Standard HTML Document Skeleton Structure Review 
<!DOCTYPE html>
<html>
  <head>
    <title>My Grade 8 Webpage</title>
  </head>
  <body>
    <p>This is my first paragraph of text on Code.org.</p>
    <p>This is a second paragraph displaying structured content.</p>
  </body>
</html>
